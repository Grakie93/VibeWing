<p align="center"><strong>Give your projects wings.</strong></p>

<p align="center">把本地项目的前后端启动、日志、构建和 Git 工作流集中到一个可视化桌面工作台。</p>

## 版本

- **v1（Electron 版）**：当前的稳定发行版。安装与使用见 [v1/README.md](v1/README.md)。
- **v2（Tauri 版）**：新一代版本，基于 Tauri。源码与说明见 [v2/](v2/)。

## 让 Coding Agent 自动导入项目（Skill）

把下面这个链接直接发给你的 Coding Agent，它会按照规范把项目 JSON 写进 VibeWing 的数据目录；你在 VibeWing 里点「重新扫描」就能看到项目，一键启动：

```text
https://raw.githubusercontent.com/Grakie93/VibeWing/main/vibewing-import.md
```

- 完整规范：[vibewing-import.md](vibewing-import.md)
- 字段模板：[vibewing.project.example.json](vibewing.project.example.json)
